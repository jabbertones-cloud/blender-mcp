# RENDER

Set explicit engine, resolution, samples, transparency, format and destination. Inspect settings after applying. Render a preview before final quality. Verify actual output dimensions and format, inspect image for clipped geometry, lighting and material defects, and confirm project can reopen. Do not equate a successful render command with visual acceptance.

## Failure policy

Stop on an unverified postcondition, preserve evidence, and retry only a scoped correction. Record what was tested and what remains subjective.

## When to use
Preparing an explicit still/animation deliverable with engine, resolution, sample count and output path.

## When not to use
Do not equate a viewport capture with final-quality rendered output, or start an expensive final render without checking settings.
