# RETOPOLOGY

Retopology is not equivalent to decimation. Define target polygon budget, edge flow around deformation zones, manifold requirements and UV preservation. Inspect mesh statistics before and after; use suitable supported Blender operations or explicitly authorized Python when no canonical tool exists. Verify normals, non-manifold edges, silhouette and deformation under test poses. Report missing automation rather than inventing a retopo tool.

## Failure policy

Stop on an unverified postcondition, preserve evidence, and retry only a scoped correction. Record what was tested and what remains subjective.
