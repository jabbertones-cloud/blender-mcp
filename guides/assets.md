# Assets — outcome guide

**Outcome:** Discover a compatible asset before importing.

## When to use
Use assets.polyhaven for licensed material/HDRI/model discovery; use assets.sketchfab only where a downloadable, permitted source is known. Confirm license, type, scale and file availability before io.import.

## When not to use
Do not treat search results as installed files, paid generators as free, or a non-downloadable preview as a working asset.

## Preconditions
Source, license, download capability, scale, intended destination and provenance

## Verification
Import to an owned collection then inspect object count, bounds, materials and external textures.

## Failure policy
Stop on unsupported or missing prerequisites, record the exact tool error and preserve existing scene content. Retry only the narrowest approved correction; do not claim a final result without readback.
