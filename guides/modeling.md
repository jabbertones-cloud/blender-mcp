# MODELING

Define object names, transforms, dimensions, topology and modifiers before execution. Inspect existing scene; create or modify only requested objects through searched canonical capabilities. Apply transforms before booleans when appropriate. Verify object count, names, dimensions, modifier state and manifoldness where relevant. Snapshot before destructive operations.

## Failure policy

Stop on an unverified postcondition, preserve evidence, and retry only a scoped correction. Record what was tested and what remains subjective.
